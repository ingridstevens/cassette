# Code of conduct

Be kind and be specific. This project is for people who work with sensitive recordings, so we also care about
privacy in how we talk to each other.

- Treat everyone with respect, whatever their experience, background, language or country.
- Criticise code and ideas, not people. Assume good faith, and say what would make something better.
- Do not post other people's recordings, transcripts, names or personal data in issues or pull requests.
- No harassment, discrimination, or personal attacks.

Maintainers may edit or remove comments, close issues and block people who break these rules. To report a problem,
contact the maintainers through a private [security advisory](https://github.com/ingridstevens/cassette/security/advisories/new)
or by email to the address on the maintainer's GitHub profile.
