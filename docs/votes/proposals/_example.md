# Example proposals (not a real roadmap)

## F1 Batch export of all projects as one zip
Export every project's Word file and CSV in one go. Adds no network access.
Cost: about 150 lines of code; new dependencies: none; size added: 0 MB; screens touched: 1 (Export menu).

## F2 Cloud sync of projects between computers
Optional account; projects are uploaded encrypted to a hosted service so they appear on a second computer.
Cost: about 3000 lines of code; new dependencies: an HTTP client and a crypto library; size added: about 5 MB; screens touched: 3 (Settings, Projects, a new sign-in sheet).

## F3 Larger text and a high-contrast theme
A text-size setting in Display and a high-contrast theme. UI only.
Cost: about 200 lines of code; new dependencies: none; size added: 0 MB; screens touched: 1 (Display settings).
