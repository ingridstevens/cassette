# Example proposals (not a real roadmap)

## F1 Batch export of all projects as one zip
Export every project's Word file and CSV in one go. Adds no network access. About 150 lines of code.

## F2 Cloud sync of projects between computers
Optional account; projects are uploaded encrypted to a hosted service so they appear on a second computer.

## F3 Larger text and a high-contrast theme
A text-size setting in Display and a high-contrast theme. UI only; no new dependencies.
