# Changelog

All notable changes are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/), and the
project will use [Semantic Versioning](https://semver.org/) once the first release is published (see the
[release milestone](https://github.com/ingridstevens/cassette/milestone/4)).

## Unreleased

### Added
- Arabic and Persian app languages with right-to-left layout (core screens translated; native review pending).
- Language model picker in the Ask tab.
- Rename a project from the toolbar title (double-click or F2).
- Info tab: the Models row opens the models folder; the docs explain how to share a models folder with a team.
- Settings: note on where models download from.

### Fixed
- The Export menu is no longer hidden under the sidebar when the toolbar wraps.
- Black pills in Settings: badges are readable.
- Work in progress is shown with a spinner, and the repeated "Transcribing…" line is gone.
- The app is named "Cassette" instead of "Electron" in menus when run from source.
